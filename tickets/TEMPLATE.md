# INC-XXXX — Short descriptive title

| Field | Value |
|---|---|
| **Ticket ID** | INC-XXXX |
| **Date opened** | YYYY-MM-DD |
| **Date resolved** | YYYY-MM-DD |
| **Priority** | Low / Medium / High |
| **Category** | Hardware / Software / Network / Account / M365 |
| **Affected system** | e.g. Windows-Lab |
| **Status** | Resolved |

## Summary

One or two sentences: what the user reported, in plain language.

## Environment

- OS / version
- Relevant software and versions
- Network context if relevant

## Symptoms

- What exactly was observed (error messages verbatim, screenshots if useful)
- When it started, what changed before it started

## Troubleshooting steps

1. Step taken → result
2. Step taken → result
3. ...

(Record dead ends too — they show the diagnostic path.)

## Root cause

The actual underlying cause, stated precisely.

## Resolution

Exact steps that fixed the issue, reproducible by someone else.

## Prevention / Notes

- How to prevent recurrence (config change, documentation, user guidance)
- Anything learned worth remembering
